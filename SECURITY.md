# Security Policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older   | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues, discussions or pull requests.

Report them privately in one of two ways:

- Use GitHub's **Report a vulnerability** button on the repository's Security tab (private vulnerability reporting).
- Email **security@webgeeksmedia.com**.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- The affected version or versions
- Your WordPress and PHP versions, if relevant

We aim to acknowledge reports within **72 hours** and to send a status update within **7 days**.

## Disclosure

We prefer coordinated disclosure. Once a fix is released, we will agree on a disclosure date with you and credit you in the changelog unless you ask us not to.

## Scope

In scope: the plugin code in this repository.

Out of scope: vulnerabilities in the third-party services the plugin connects to (Google Vertex AI, Pinecone, Anthropic, OpenAI). Please report those to the service provider.
